\section{Passive 3D Rotation Matrices}\label{\chabbr:sec:passive3D}

In the first part of this chapter, we cover 3D rotations in their most basic representation, namely by means of $3\times 3$ rotation matrices. Since it is straightforward to switch between active and passive rotations, we will concentrate on the treatment of passive rotations, since material texture analysis relies mostly on passive rotations, and we will mention expressions for active rotations as footnotes.

\subsection{Single rotations}\label{\chabbr:ssec:single3Drotationmatrices}

For a passive 3D rotation, we go from the old to the new reference frame using the same relation as for the 2D case, but now the subscripts run from $1$ to $3$:
\[
	\mathbf{e}'_i = (\mathbf{e}'_i\cdot\mathbf{e}_j)\mathbf{e}_j = R^p_{ij}\mathbf{e}_j\ .
\]
The components of the rotated vector $\mathbf{r}'$ are again given by the expression $r'_i = R^p_{ij}r_j$ as for the 2D case.  Note that the components of the new basis vector $\mathbf{e}'_i$ with respect to the old basis vectors are written on \textit{row}\footnote{Note that for active rotations, the components of the new basis vector would be entered as columns, not as rows.} $i$ of the rotation matrix $R^p$. For the inverse of the rotation $R^p_{ij}$, we write:
\[
	\mathbf{e}_i = (\mathbf{e}_i\cdot\mathbf{e}'_j)\mathbf{e}'_j = (R^p)^{-1}_{ij}\mathbf{e}'_j\ .
\]
The dot product is commutative, so the nine dot products in this relation are the same as in the previous case, but they are written in the transposed order.  In other words, the components of the new vectors $\mathbf{e}'_j$ with respect to the old vectors $\mathbf{e}_i$ are written as the \textit{columns} of the inverse rotation matrix.  Since we have only flipped the subscripts $i$ and $j$ in going from the first relation to the second, we find that the inverse of a rotation matrix is given by the transpose of that matrix, or
\[
	(R^p)^{-1} = (R^p)^T\ .
\]
This is an important property of rotation matrices and is valid for any arbitrary rotation.  Since we have:
\begin{equation}
	R^p_{ij} (R^p)^{-1}_{jk} = \delta_{ik}\ ,\label{\chabbr:eq:RRinv}
\end{equation}
we must also have (converting the inverse to the transpose):
\begin{equation}
	R^p_{ij} \left((R^p)^T\right)_{jk} = \delta_{ik}\ .
\end{equation}
If we interpret each row of the matrix as a $3$-component vector, then this relation states that the dot product of each row with itself is equal to $1$, whereas the dot products between different rows are equal to $0$.  Interchanging the order of the matrices in eq.~(\ref{\chabbr:eq:RRinv}) we can show that we must have the same property for the column vectors:
\begin{equation}
	(R^p)^{-1}_{ij}R^p_{jk} = \delta_{ik} \rightarrow \left((R^p)^T\right)_{ij} R^p_{jk} = \delta_{ik}\ .
\end{equation}
The relations in this section are valid for both active and passive matrices; we can view an active rotation matrix as a passive matrix with the opposite rotation angle, as we illustrated in the 2D case.  All $3\times 3$ matrices that satisfy these relations (i.e., $R^{-1}=R^T$) are known as \textit{orthogonal matrices}\index{orthogonal matrices}.  In addition, one can show that the determinant of a rotation matrix must always be equal to $+1$; orthogonal matrices with determinant equal to $+1$ are known as \textit{special orthogonal matrices}\index{special orthogonal matrix}\index{orthogonal matrix!special}.  They belong to the set $SO(3)$, the set of all special orthogonal $3\times 3$ matrices, which is commonly known as the \textit{3D rotation group};\index{rotation group}\index{$SO(3)$}  $SO(3)$ is a group with respect to the operation of rotation composition, which we will discuss next.

\subsection{3D rotation composition}\label{\chabbr:ssec:3Drotationcomposition}

It is easy to convince yourself, using a non-symmetric object, that, in general, the order in which 3D active rotations are executed, matters; reversing the order of two active rotations produces a different outcome for an object in the same starting orientation, and the same is true for passive rotations.\footnote{For the passive case, instead of using a single non-symmetric object, one could hold three pencils with different colors perpendicular to each other, and perform two different rotations to the triad in opposite order.  While this involves some amount of dexterity, it is not too difficult to see that passive rotations do not commute either.} For the composition of two passive rotations, $R^p_1$ first, followed by $R^p_2$, we know from the 2D analysis that we must write the matrices from left to right:
\begin{equation}
	\mathbf{r}'' = R^p_1 R^p_2\mathbf{r}\ .
\end{equation}

\lightgraybox{
{\small\sffamily\begin{example}
Consider the following rotations:
\begin{align*}
	R^p_1 &= 90^{\circ}@[100]\ ;\\
	R^p_2 &= 90^{\circ}@[001]\ .	
\end{align*}
We introduce here a simple notation of the form $\omega @[\beta_1\beta_2\beta_3]$, which stands for a passive rotation by an angle $\omega$ around an axis with direction cosines $(\beta_1,\beta_2,\beta_3)$.  It is easy to show that the resulting passive matrices are given by:
\[
	R^p_1 = \begin{pmatrix}
	1 & 0 & 0\\
	0 & 0 & 1\\
	0 & -1 & 0\end{pmatrix}\ ; \qquad
	R^p_2 = \begin{pmatrix}
	0 & 1 & 0\\
	-1 & 0 & 0\\
	0 & 0 & 1\end{pmatrix}\ .
\]
Hence, the composition of the matrices results in the rotation $R^p_3$, given by the matrix:
\[
	R^p_3 = R^p_1 R^p_2 = \begin{pmatrix}
	0 & 1 & 0\\
	0 & 0 & 1\\
	1 & 0 & 0\end{pmatrix}\ .
\]
Application to the column vector $\mathbf{r}=(0,1,0)^T$, we find $R^p_2(0,1,0)^T = (1,0,0)^T$ and $R^p_1(1,0,0)^T = (1,0,0)^T$; clearly we also have $R^p_3(0,1,0)^T=(1,0,0)^T$. In the reverse order, we have $R^p_1(0,1,0)^T = (1,0,0)^T$ and $R^p_2(1,0,0)^T=(-1,0,0)^T$, which is a different vector.  Hence, 3D rotations do not commute in general; the only time they do commute is when both rotations have the same rotation axis.
\end{example}}}

In later sections we will introduce additional ways to compose multiple rotations using rotation representations  that are more suitable for such operations.  In particular, we will see how to compose rotations using generalized complex numbers or quaternions.

\section{Euler Angles and their Properties}\label{\chabbr:sec:eulerangles}

\subsection{Definitions}\label{\chabbr:ssec:definitions}
Euler has shown that every 3D rotation can be decomposed into three separate rotations around the coordinate axes $x$, $y$ and $z$. This decomposition, however, is not unique since there are several ways in which the axes and their ordering can be chosen.  One distinguishes decompositions in which the three axes are different from those where two of the rotations are around a similarly named axis.  In the former case, one refers to the three rotation angles at \textit{Tait-Bryan angles}\index{Tait-Bryan angles}; in the latter case they are generically known as \textit{Euler angles}\index{Euler angles}.  

Tait-Bryan angles are used to describe the independent motions of ships and aircraft.  If we attach a Cartesian reference frame to the center-of-mass of an airplane, such that the $x$ axis points towards the nose, the $y$ axis along the left wing, and the $z$ axis normal to the plane of the wings, then one can distinguish between three independent movements: the tail rudder is used to rotate the plane around the $z$ axis (\indexit{yaw}), the elevators in the tail raise of lower the nose by rotating the plane around the $y$ axis (\indexit{pitch}), and the ailerons in the wings allow for rotation around the $x$ axis (\indexit{roll}).  Obviously we can change the orientation of the reference frame from this $x-y-z$ case to $x$-$z$-$y$, $z$-$x$-$y$, and so on, for a total of six possible definitions; while the names yaw, pitch, and roll do not change, the corresponding axis symbol depends on the choice of the reference frame.  Mathematically, one must therefore fix the order of the three rotations, and it becomes important to state explicitly which reference frame convention is made before carrying out any numerical computations.

For Euler angles, the same is true, but the choice of reference frame is limited to two symbols instead of three; in texture analysis, the most commonly used convention is the \indexit{Bunge convention}, in which the rotation order is $z$-$x$-$z$, with angle symbols $(\varphi_1,\Phi,\varphi_2)$.  The first rotation is by an angle $\varphi_1$ around the $z$ axis (see Fig.~\ref{\chabbr:fig:eulers}(a-b)); the allowed range of this angle is $[0,2\pi]$. The second rotation takes place around the new $x'$ axis by an angle $\Phi$ in the range $[0,\pi]$ (see Fig.~\ref{\chabbr:fig:eulers}(b-c)); and the final rotation is by an angle $\varphi_2$ around the new $z''$ axis, with the angle in the range $[0,2\pi]$ (see Fig.~\ref{\chabbr:fig:eulers}(c-d)).  Since we are rotating the reference frames, the Euler rotations are passive rotations.

For each rotation, we can write down a passive rotation matrix.  The first rotation, $R^p(\varphi_1)$, relates the reference
frame \textcolor{OCCarnegieRed}{$\mathbf{e}'_i$} to the reference frame \textcolor{OCGreenThread}{$\mathbf{e}_i$}, and is given by:
\begin{equation}
	\textcolor{OCCarnegieRed}{\mathbf{e}'_i} = R_z(\varphi_1)_{ij} \textcolor{OCGreenThread}{\mathbf{e}_j} \rightarrow \begin{pmatrix}\textcolor{OCCarnegieRed}{\mathbf{e}'_x}\\ \textcolor{OCCarnegieRed}{\mathbf{e}'_y}\\ \textcolor{OCCarnegieRed}{\mathbf{e}'_z}\end{pmatrix} = 
	\begin{pmatrix}\cos\varphi_1&\sin\varphi_1&0\\ -\sin\varphi_1&\cos\varphi_1&0\\ 0&0&1\end{pmatrix}
	\begin{pmatrix}\textcolor{OCGreenThread}{\mathbf{e}_x}\\ \textcolor{OCGreenThread}{\mathbf{e}_y}\\ \textcolor{OCGreenThread}{\mathbf{e}_z}\end{pmatrix}\ . 
\end{equation}
The second rotation brings the reference frame \textcolor{OCCarnegieRed}{$\mathbf{e}'_i$} to \textcolor{OCblue}{$\mathbf{e}''_i$} by a counterclockwise rotation of 
$\Phi$ around the  \textcolor{OCCarnegieRed}{$\mathbf{e}'_x$} axis.  It is represented by:
\begin{equation}
	\textcolor{OCblue}{\mathbf{e}''_i} = R_x(\Phi)_{ij} \textcolor{OCCarnegieRed}{\mathbf{e}'_j} \rightarrow \begin{pmatrix}\textcolor{OCblue}{\mathbf{e}''_x}\\ \textcolor{OCblue}{\mathbf{e}''_y}\\ \textcolor{OCblue}{\mathbf{e}''_z}\end{pmatrix} = 
	\begin{pmatrix}1&0&0\\ 0&\cos\Phi&\sin\Phi\\ 0&-\sin\Phi&\cos\Phi\end{pmatrix}
	\begin{pmatrix}\textcolor{OCCarnegieRed}{\mathbf{e}'_x}\\ \textcolor{OCCarnegieRed}{\mathbf{e}'_y}\\ \textcolor{OCCarnegieRed}{\mathbf{e}'_z}\end{pmatrix}\ . 
\end{equation}

\begin{figure}[ht]
\centering\leavevmode
\includegraphics{\graphicspath EulerRotations.pdf}
\caption{\label{\chabbr:fig:eulers}Illustration of the three Bunge Euler angles, one step at a time.}
\end{figure}

The final rotation of $\varphi_2$ around the new \textcolor{OCblue}{$\mathbf{e}''_{z}$} axis is described by:
\begin{equation}
	\textcolor{OClightblue}{\mathbf{e}'''_i} = R_z(\varphi_2)_{ij} \textcolor{OCblue}{\mathbf{e}''_j} \rightarrow \begin{pmatrix}\textcolor{OClightblue}{\mathbf{e}'''_x}\\ \textcolor{OClightblue}{\mathbf{e}'''_y}\\ \textcolor{OClightblue}{\mathbf{e}'''_z}\end{pmatrix} = 
	\begin{pmatrix}\cos\varphi_2&\sin\varphi_2&0\\ -\sin\varphi_2&\cos\varphi_2&0\\ 0&0&1\end{pmatrix}
	\begin{pmatrix}\textcolor{OCblue}{\mathbf{e}''_x}\\ \textcolor{OCblue}{\mathbf{e}''_y}\\ \textcolor{OCblue}{\mathbf{e}''_z}\end{pmatrix}\ . 
\end{equation}
This leads to the following relation between the reference frames \textcolor{OClightblue}{$\mathbf{e}'''_i$} and \textcolor{OCGreenThread}{$\mathbf{e}_i$}; for 
brevity, we write $c_i\equiv\cos\varphi_i$, $s_i\equiv\sin\varphi_i$, $c\equiv\cos\Phi$, and $s\equiv\sin\Phi$:
%{\small 
\begin{equation}
	\begin{pmatrix}\textcolor{OClightblue}{\mathbf{e}'''_x}\\ \textcolor{OClightblue}{\mathbf{e}'''_y}\\ \textcolor{OClightblue}{\mathbf{e}'''_z}\end{pmatrix} = 
	\begin{pmatrix}c_2&s_2&0\\ -s_2&c_2&0\\ 0&0&1\end{pmatrix}
	\begin{pmatrix}1&0&0\\ 0&c&s\\ 0&-s&c\end{pmatrix}
	\begin{pmatrix}c_1&s_1&0\\ -s_1&c_1&0\\ 0&0&1\end{pmatrix}
	\begin{pmatrix}\textcolor{OCGreenThread}{\mathbf{e}_x}\\ \textcolor{OCGreenThread}{\mathbf{e}_y}\\ \textcolor{OCGreenThread}{\mathbf{e}_z}\end{pmatrix}\ . 
\end{equation}%}
The product of the three matrices can be worked out easily, and is given by:
\begin{equation}
	\mathbf{g}_{ij}(\varphi_1,\Phi,\varphi_2) = \begin{pmatrix}c_1c_2-s_1cs_2&s_1c_2+c_1cs_2&ss_2\\
	-c_1s_2-s_1cc_2&-s_1s_2+c_1cc_2&sc_2\\
	s_1s&-c_1s&c\end{pmatrix}\ .\label{\chabbr:eq:eulermatrix}
\end{equation}
Note that this matrix is often represented with a bold symbol.  This is customary in the texture literature, and the symbol $\mathbf{g}$ is known as the \textit{orientation matrix}. 

\begin{exercise}
Show that the matrix $\mathbf{g}_{ij}$ is an orthogonal matrix.
\end{exercise}

The meaning of the Bunge rotation angles is easy to understand in the context of crystalline materials.  Looking at Fig.~\ref{\chabbr:fig:eulers}(a), we can consider the green reference frame to be the external sample frame (or the laboratory frame). For an unrotated crystal, we assume that the crystallographic $\mathbf{c}$ axis is initially parallel to the $z$ axis of the sample reference frame.  The first two Bunge rotations, $\varphi_1$ and $\Phi$, then describe how this $\mathbf{c}$ axis is oriented with respect to the sample frame (this is the $z''$ axis in Fig.~\ref{\chabbr:fig:eulers}(c)).  The final Bunge angle, $\varphi_2$, describes the rotation of the crystal around its $\mathbf{c}$ axis.  In reading the literature of materials textures, one should pay careful attention to the nature of the final rotation matrix $\mathbf{g}_{ij}$: in the description of Fig.~\ref{\chabbr:fig:eulers}, the Euler angle triplet describes the orientation of the crystal reference frame with respect to the external reference frame.  It is also possible to describe the orientation in the opposite way, i.e., the rotation of the external reference frame with respect to the crystal reference frame; that rotation matrix would then be the transpose of the matrix in Eq.~(\ref{\chabbr:eq:eulermatrix}).


\subsection{Alternative Euler triplet definitions}\label{\chabbr:sec:Eulteralternatives}
While the Bunge convention is the most widely used Euler triplet, there are other forms used throughout the texture literature. The Roe and Kocks triplets use rotation axes $z$-$y$-$z$, the Canova triplet uses $z$-$x$-$z$:
\begin{itemize}
\item \indexit{Roe Euler Angles}: They are represented by the triplet $(\Psi, \Theta, \Phi)$; as for the Bunge angles, the first two angles determine the orientation of the crystal's $\mathbf{c}$ axis, the third angle rotates the crystal around this axis.
\item \indexit{Kocks Euler Angles}: They are represented by the triplet $(\Psi, \Theta, \phi)$; the first two angles are identical to the Roe Euler angles, but the third one represents a clockwise rotation instead of a counterclockwise rotation, so the angle $\phi$ has the opposite sign.
\item \indexit{Canova Euler Angles}: They are represented by the triplet $(\omega,\theta,\phi)$ and can be considered to be the inverse of the Bunge angles in the sense that they produce the transpose of the Bunge rotation matrix.
\end{itemize}
Conversion relations between these representations can be determined by comparing the $3\times 3$ rotation matrices for each pair of representations. The results of such a comparison are shown in Table~\ref{\chabbr:tb:Eulerconversions} which lists the transformations to go from each system to the Bunge system.

\begin{table}[h]
\centering\leavevmode
\begin{tabular}{|l|cccc|}
\hline
Bunge & $\varphi_1$ & $\Phi$ & $\varphi_2$ &  $z$-$x$-$z$ \\
\hline
Kocks & $\Psi+\frac{\pi}{2}$ & $\Theta$ & $\frac{\pi}{2}-\phi$ & $z$-$y$-$z$\\
Roe    & $\Psi+\frac{\pi}{2}$ & $\Theta$ & $\Phi-\frac{\pi}{2}$ & $z$-$y$-$z$\\
Canova & $-\phi$& $-\theta$ & $-\omega$ & $z$-$x$-$z$\\
\hline
\end{tabular}
\caption{\label{\chabbr:tb:Eulerconversions}Conversion relations from Euler triplets also used in the texture literature to the more common Bunge representation.}
\end{table}





\subsection{Graphical representation of Euler space}\label{\chabbr:sec:eulerspace}
The Bunge Euler angle triplet can be represented as a point inside a 3D rectangular box with each angle varying along one of the box edges. It is customary to draw this box such that the $\varphi_1$ and $\varphi_2$ axes lie in the bottom plane of the box and the $\Phi$ axis is vertical, as shown in Fig.~\ref{\chabbr:fig:euleridentity}(a). Note that the box edges have lengths $[2\pi, \pi, 2\pi]$ along $(\varphi_1,\Phi,\varphi_2)$, respectively. Note also that this is essentially a left-handed reference frame, considering the ordering of the angles in the Bunge triplet.  It is important to point out that this Euler box is periodic along the two horizontal axes, \textit{but not along the $\Phi$ axis}.  In other words, it is easy to see from the matrix form in eq.~(\ref{\chabbr:eq:eulermatrix}) that adding $2\pi$ to either $\varphi_1$ or $\varphi_2$ does not alter the matrix at all:
\begin{align*}
	\mathbf{g}_{ij}(\varphi_1,\Phi,\varphi_2) &=\mathbf{g}_{ij}(\varphi_1+2\pi,\Phi,\varphi_2)\ ;\\
	\mathbf{g}_{ij}(\varphi_1,\Phi,\varphi_2) &=\mathbf{g}_{ij}(\varphi_1,\Phi,\varphi_2+2\pi)\ .
\end{align*}
However, along the $\Phi$ axis, which has a range from $0$ to $\pi$, such a relation does not hold:
\[
	\mathbf{g}_{ij}(\varphi_1,\Phi,\varphi_2) \ne \mathbf{g}_{ij}(\varphi_1,\Phi+\pi,\varphi_2)
\]
since $\cos(\Phi+\pi)=-\cos\Phi$ and $\sin(\Phi+\pi)=-\sin\Phi$.  Even though Euler space is drawn with a range of $[0,\pi]$ along $\Phi$, is is clear that the rotation matrix is invariant when we replace $\Phi$ by $\Phi+2\pi$; this means that the upper half of the periodic cell, i.e., the part for $\Phi\in[\pi,2\pi]$, is not simply related to the lower half by a translation.  In fact, it is easy to show that the following relation holds:
\begin{equation}
	\mathbf{g}_{ij}(\varphi_1,\Phi,\varphi_2) = \mathbf{g}_{ij}(\varphi_1+\pi,2\pi-\Phi,\varphi_2+\pi)\ .\label{\chabbr:eq:eulerglide}
\end{equation}
The translation of $(\pi,0,\pi)$ in the $(\varphi_1,\varphi_2)$ plane along with the mirror operation from $\Phi$ to $2\pi-\Phi$ indicates that the top half of the cell is related to the lower half by a mirror glide operation. The combination of the $2\pi$ periodicity along the three axes when considering a $[2\pi,2\pi,2\pi]$ cell and the glide plane at $\Phi=\pi$ means that the true symmetry of Euler space is given by the monoclinic space group $\mathbf{Pc}$.   This, in turn, indicates that the choice of a right angle between the $\varphi_1$ and $\varphi_2$ axes is one of convenience, and hides the true underlying symmetry of Euler space.\footnote{In section~\ref{\chabbr:sec:quateuler} we will show that the true Euler unit cell is, in fact, a cell of size $[4\pi, 4\pi, 4\pi]$; in practice, however, one only makes use of a $[2\pi,\pi,2\pi]$ sub-cell.}

\begin{figure}[ht]
\centering\leavevmode
\includegraphics[width=\textwidth]{\graphicspath Euler1}
\caption{\label{\chabbr:fig:euleridentity}(a) The basic cell of the Euler space representation, drawn as a rectangular prism; (b) representation of the identity as a set of parallel lines.}
\end{figure}


If we put $\Phi=0$ or $\pi$ in Eq.~(\ref{\chabbr:eq:eulermatrix}), then we obtain the following expression:
\begin{align}
	\mathbf{g}_{ij}(\varphi_1,0,\varphi_2) &= \begin{pmatrix}c_1c_2-s_1s_2&s_1c_2+c_1s_2&0\\
	-c_1s_2-s_1c_2&-s_1s_2+c_1c_2&0\\
	0&0&1\end{pmatrix}\ ;\nonumber\\
	&=  \begin{pmatrix}\cos(\varphi_1+\varphi_2)&\sin(\varphi_1+\varphi_2)&0\\ -\sin(\varphi_1+\varphi_2)&\cos(\varphi_1+\varphi_2)&0\\ 0&0&1\end{pmatrix}\ .\label{\chabbr:eq:eulermatrix2}
\end{align}
In other words, when $\Phi=0$, the Euler angle triplet $(\varphi_1,0,\varphi_2)$ represents a rotation around the $\mathbf{e}_z$ axis by an angle $\varphi_1+\varphi_2$.  If we now select $\varphi_2=-\varphi_1$, then we obtain the identity rotation matrix $\delta_{ij}$; this is a bit of a disconcerting result since it means that \textit{all Euler triplets of the form $(\varphi_1,0,2\pi n-\varphi_1)$ with $n$ an arbitrary integer represent the identity orientation}.  Apart from the periodicity of Euler space, there is hence no unique Euler angle triplet inside the basic cell that represents the identity; we say that, in the Euler representation, the identity rotation is \textit{infinitely degenerate}.  Graphically, we represent the triplets of the form $(\varphi_1,0,2\pi n-\varphi_1)$ by the diagonal red lines with equation $\varphi_2=2\pi n-\varphi_1$ in the bottom $\Phi=0$ plane of the Euler cell (Fig.~\ref{\chabbr:fig:euleridentity})(b).  The degeneracy of the identity orientation is clearly not a desirable mathematical property of the Euler representation.  In fact, \textit{for any rotation by an angle $\varphi$ around the $\mathbf{e}_z$ axis, the Euler representation is infinitely degenerate} since we can write the Euler triplet as $(\varphi_1,0,\varphi-\varphi_1)$ or $(\varphi+\varphi_1,0,-\varphi_1)$ with $\varphi_1$ an arbitrary angle.  This means that one must be careful in numerical applications whenever $\Phi=0$ or $\Phi=\pi$.  The underlying reason for the infinite degeneracies if the fact that, as we will discus in the next section (section~\ref{\chabbr:sec:eulermetric}), the Euler volume element vanishes for $\Phi=n\pi$ for $n\in\mathbb{Z}$. 

Despite this mathematical inconvenience, the Euler angle orientation/rotation representation has become the standard in the texture literature, and we will use it frequently throughout this text.  There are several other orientation representations that do not suffer from this kind of degeneracies, and we will take a closer look at the important class of \textit{neo-Eulerian} representations in section~\ref{\chabbr:sec:neoEulerian}.


\subsection{Metric properties of Euler angle triplets}\label{\chabbr:sec:eulermetric}
When working with polycrystalline microstructures, one often encounters the problem of computing the effective value of a material property, averaged over the distribution of grain orientations.\footnote{This section is more advanced mathematically and may be skipped on first reading.}  If we represent the \indexit{Orientation Distribution Function} or ODF as a function $f$ of the Euler angles, i.e., $f(\varphi_1,\Phi,\varphi_2)$, then the averaging process will invariably involve an integration over the entire range of the three Euler angles. This, in turn, will require that we know the correct volume element, $\mathrm{d}V$, for Euler space which involves the computation of the metric tensor.  

We must first determine how the Euler rotation matrix in Eq.~(\ref{\chabbr:eq:eulermatrix}) changes when we perform infinitesimal rotations, $\mathrm{d}\varphi_1$, $\mathrm{d}\Phi$, and $\mathrm{d}\varphi_2$,  around each of the rotation axes. If we represent the matrix by $R$ as a short-hand notation, then the change of the matrix with respect to each Euler angle is given by the following derivatives (using the same abbreviated notation as before and representing $q_1=\varphi_1$, $q_2=\Phi$ and $q_3=\varphi_2$):
\[
	\frac{\partial R}{\partial q_1} = \begin{pmatrix}-c_2s_1-cc_1s_2&c_1c_2-cs_1s_2& 0\\
	-cc_1c_2+s_1s_2&-cc_2s_1-c_1s_2&0\\
	c_1s & ss_1 & 0\end{pmatrix}
\]
\[
	\frac{\partial R}{\partial q_2} = \begin{pmatrix}ss_1s_2&-c_1ss_2&cs_2\\
	c_2ss_1 & -c_1c_2s &cc_2\\
	cs_1&-cc_1&-s\end{pmatrix}
\]
\[
	\frac{\partial R}{\partial q_3} = \begin{pmatrix}-cc_2s_1-c_1s_2&cc_1c_2-s_1s_2&c_2s\\
	-c_1c_2+cs_1s_2&-c_2s_1-cc_1s_2&-ss_2\\
	0&0&0\end{pmatrix}
\]
The theory of differential geometry [CITATION] then tells us that the metric tensor, $g_{ij}$, of Euler space can be expressed in terms of these derivative matrices as:
\[
	g_{ij} = \frac{1}{2}\text{Tr}\left[ \left(\frac{\partial R}{\partial q_i}\right)^T\,\frac{\partial R}{\partial q_j}\right]\ ,
\]
where we have matrix multiplication between the square brackets and Tr indicates the matrix trace.  As an example, we compute $g_{13}$ as:
{\small\begin{equation*}
\begin{split}
	g_{13} &= \frac{1}{2} \text{Tr}\left[ \begin{pmatrix}
	-c_2s_1-cc_1s_2&-cc_1c_2+s_1s_2&c_1s \\
	c_1c_2-cs_1s_2&-cc_2s_1-c_1s_2&ss_1\\
	 0& 0 & 0\end{pmatrix}\begin{pmatrix}-cc_2s_1-c_1s_2&cc_1c_2-s_1s_2&c_2s\\
	-c_1c_2+cs_1s_2&-c_2s_1-cc_1s_2&-ss_2\\
	0&0&0\end{pmatrix}\right];\\
	&= \frac{1}{2} \text{Tr}\begin{pmatrix}c&0&-ss_1\\ 0& c& c_1s\\ 0&0&0\end{pmatrix};\\
	&= c = \cos\Phi.
\end{split}
\end{equation*}}
Repeating this computation for all entries of the metric tensor results in:
\begin{equation}
	g_{ij} = \begin{bmatrix}1&0&\cos\Phi\\0&1&0\\ \cos\Phi& 0& 1\end{bmatrix}\ .
\end{equation}
Note that this tensor is constant in planes normal to the $\Phi$ axis in the Euler cell.  The relevant Euler volume element, $\mathrm{d}V$ is then the product of the differentials and the volume, derived as the square root of the determinant of the metric tensor; the determinant equals $\det\vert g_{ij}\vert = 1-\cos^2\Phi$ so that (restricting $\Phi$ to the interval $[0,\pi]$):
\begin{equation}
	\mathrm{d}V = \sin\Phi\,\mathrm{d}\varphi_1\,\mathrm{d}\Phi\,\mathrm{d}\varphi_2\ .\label{\chabbr:eq:EulerdV}
\end{equation}
This, in turn, allows us to compute the volume of the Euler space box introduced in the previous section.  A naive computation, ignoring the metric properties of Euler space, would result in a volume that is $2\pi\times \pi\times 2\pi=4\pi^3$.  The correct result is obtained by integrating the volume element over the full range of the coordinates:
\begin{equation}
	V = \int_0^{2\pi}\!\!\!\mathrm{d}\varphi_1\,\int_0^{\pi}\!\!\!\mathrm{d}\Phi\,\sin\Phi\,\int_0^{2\pi}\!\!\!\mathrm{d}\varphi_2 = 8\pi^2\ ,\label{\chabbr:eq:EulerVolume}
\end{equation}
since the integral over $\Phi$ results in a value of $2$.  

Knowledge of the metric tensor also allows for the determination of the infinitesimal line segment $\mathrm{d}s$ (employing the summation convention):
\begin{equation}
	{\mathrm{d}s}^2 = \mathrm{d}q_i\,g_{ij}\,\mathrm{d}q_j = {\mathrm{d}\varphi_1}^2+{\mathrm{d}\Phi}^2+{\mathrm{d}\varphi_2}^2+2\cos\Phi\,\mathrm{d}\varphi_1\mathrm{d}\varphi_2\ .\label{\chabbr:eq:Eulerds}
\end{equation}


Returning to the comments in the first paragraph of this section, we are now ready to compute the average value of any material property, $P$, given an ODF $f(\varphi_1,\Phi,\varphi_2)$:
\begin{equation}
	\langle P\rangle = \frac{1}{8\pi^2} \int_0^{2\pi}\!\!\!\mathrm{d}\varphi_1\,\int_0^{\pi}\!\!\!\mathrm{d}\Phi\,\sin\Phi\,\int_0^{2\pi}\!\!\!\mathrm{d}\varphi_2\, f(\varphi_1,\Phi,\varphi_2)\, P(\varphi_1,\Phi,\varphi_2)\ ;
\end{equation}
in general, the quantity $P$ will also depend on the Euler angles.\footnote{In general, $P$ will be a property tensor (see chapter~\ref{TENSOR:tensors}) and the integrand will have one rotation matrix $R$ for each subscript of the tensor.}  In practical terms, the ODF represents the volume fraction of material that has a given orientation. 


\section{Neo-Eulerian Rotation Representations}\label{\chabbr:sec:neoEulerian}

\subsection{Definitions}\label{\chabbr:ssec:neodefinitions}

\indexit{Sir Charles Frank} introduced the name \indexit{neo-Eulerian} \cite{frank1988a} to label a family of orientation/rotation representations with a common mathematical form. If we use the standard representation of a rotation by a counterclockwise angle $\omega$ around a unit rotation axis $\hat{\mathbf{n}}$, then a neo-Eulerian representation is a vector $\mathbf{e}(\omega,\hat{\mathbf{n}})$ of the form:\footnote{The choice of the symbol $\mathbf{e}$ for the neo-Eulerian vector is not particularly important; below we will introduce specific notations for each of the commonly used neo-Eulerian representations.}
\begin{equation}
	\mathbf{e}(\omega,\hat{\mathbf{n}}) = \hat{\mathbf{n}}\,f(\omega)\ ,\label{\chabbr:eq:neoEulerian}
\end{equation}
where the function $f(\omega)$ is a monotonically increasing function of the angle $\omega\in[0,\pi]$ and $f(0)=0$.  

%The reason for the minus sign in this definition is subtle and has to do with the need for all neo-Eulerian representations to be consistent with the rotation matrix representation when converting between representations; the detailed reasoning can be found in \cite{degraef2015t}.  

While there is an infinite choice for the function $f(\omega)$, a handful of functions have over the years turned out to be useful for rotation representations. In the texture community we make frequent use of the following monotonic functions:

\begin{itemize}
	\item \textcolor{OCSkiboRed}{$f(\omega) = \omega$}: this is the simplest option, resulting in the \indexit{rotation vector} $\mathbf{R}=\omega\,\hat{\mathbf{n}}$. The collection of all possible rotation vectors can be represented geometrically by a closed ball of radius $\pi$, i.e., $\mathbb{B}^3_{\pi}$. The magnitude of the rotation angle is simply the distance to the origin, and all rotations by an angle $\omega=\pi$ lie on the surface of the ball, i.e., on the 2-sphere $\mathbb{S}^2_{\pi}$.  The rotation vector can be a convenient tool for the visualization of collections of orientations/rotations, but it is not very useful for numerical work.
	
	\item \textcolor{OCSkiboRed}{$f(\omega) = \tan\frac{\omega}{2}$}: this function generates the \indexit{Rodrigues vector}, $\bm{\rho}= \tan\frac{\omega}{2}\,\hat{\mathbf{n}}$.  Since the domain of the angle $\omega$ is $[0,\pi]$ we see that the Rodrigues vectors occupy an infinite space; all rotations by an angle $\omega=\pi$ lie at infinity due to the divergence of the tangent function for argument $\pi/2$.  All rotations by an angle $\omega=\pi/2$ lie at unit distance from the origin since $\tan(\pi/4)=1$.  The mathematical space of the Rodrigues vectors is essentially $\mathbb{R}^3$, but, as described in section~\ref{\chabbr:ssec:neoEulerianmetric}, Rodrigues space does not have a Cartesian metric.  This representation is very important to the texture community because (1) there is a closed-form expression for the concatenation of multiple rotations (see section~\ref{\chabbr:ssec:neoEuleriancomposition}), and (2) the space allows for a particularly convenient description of the rotational symmetry of crystal structures.
\end{itemize}

\noindent The next three representations are related to the concept of \indexit{quaternions}, i.e., 4D complex numbers introduced in chapter~\ref{NUMSYS:NumberSystems} on Number Systems (see section~\ref{NUMSYS:sec:quaternions}). Eq.~(\ref{NUMSYS:eq:quatrot}) describes the relation between a unit quaternion and a 3D rotation:
\begin{equation}
	q = \left[\cos\frac{\omega}{2},\sin\frac{\omega}{2}\,\hat{\mathbf{n}}\right] = [q_0,\mathbf{q}].
\end{equation}
Note that the Rodrigues vector introduced above is related to the quaternion as follows:
\begin{equation}
	\bm{\rho} = \frac{\mathbf{q}}{q_0} = \frac{\sin\frac{\omega}{2}}{\cos\frac{\omega}{2}}\,\hat{\mathbf{n}} = \tan\frac{\omega}{2}\,\hat{\mathbf{n}}\ .
\end{equation}

\begin{itemize}
	\item \textcolor{OCSkiboRed}{$f(\omega) = \sin\frac{\omega}{2}$}: We see that this function is present in the vector part of the quaternion, i.e., $\mathbf{q}=\sin\frac{\omega}{2}\,\hat{\mathbf{n}}$.  These vectors end in points that lie inside or on the surface of a unit ball $\mathbb{B}^3$, with the surface $\mathbb{S}^2$ once again representing  the rotations by an angle $\omega=\pi$.  
	\item \textcolor{OCSkiboRed}{$f(\omega) = \tan\frac{\omega}{4}$}: Since all unit quaternions reside on the 3-sphere, $\mathbb{S}^3$, we can perform an angle-preserving \indexit{stereographic projection} to the unit 3-ball $\mathbb{B}^3$. As described in chapter~\ref{PROJTS:Projections} (section~\ref{PROJTS:sec:SPprops}) the mathematical description of the stereographic projection simply requires taking  $N-1$ components of the unit vector and dividing them by the remaining component.  For the unit quaternion above, we take the scalar part $q_0$ to represent that remaining component and we arrive at the \indexit{3D stereographic vector}
	\[
		\mathbf{s} = \frac{\mathbf{q}}{1+q_0} = \frac{\sin\frac{\omega}{2}}{1+\cos\frac{\omega}{2}}\,\hat{\mathbf{n}} = \tan\frac{\omega}{4}\,\hat{\mathbf{n}}\ .
	\]
	\item \textcolor{OCSkiboRed}{$f(\omega) = [3(\omega-\sin\omega)/4]^{1/3}$}:	in section~\ref{PROJTS:sec:lambertproj} we introduced the Lambert projection from the 2-sphere $\mathbb{S}^2$ to the 2-ball (disc) $\mathbb{B}^2_2$ with radius $R=2$, and we showed by means of an example that this is an area-preserving mapping.  Some sophisticated math (\cite{degraef2014r}) shows that, if we increase the dimensions by one, we obtain a generalized Lambert projection between the 3-sphere $\mathbb{S}^3$ and the 3-ball $\mathbb{B}^3_{\rho}$ where $\rho=[3\pi/4]^{1/3}$.  The function that achieves this \indexit{equal-volume mapping} is precisely the function $f(\omega) = [3(\omega-\sin\omega)/4]^{1/3}$.  In the texture community, this representation is known as the \indexit{homochoric representation}, and we have the \indexit{homochoric vector} $\mathbf{h}=  [3(\omega-\sin\omega)/4]^{1/3}\,\hat{\mathbf{n}}$.\footnote{It should be noted that the expression $\omega-\sin\omega=h$ with $h$ some constant is a transcendental equation that does not have a closed form solution; hence, to extract the rotation angle from a homochoric vector one must use a numerical procedure, such as the Newton-Raphson method.  Interestingly, this equation is known as \indexit{Kepler's Equation}, an important equation for orbital mechanics.} 
\end{itemize}
 
\noindent Contrary to the Euler angle representation, for which the identity is infinitely degenerate, in the neo-Eulerian representations there are no degeneracies related to the identity; in all cases the identity is a single point at the origin of an orthonormal reference frame (Rodrigues vectors) or at the center of a ball (all others). All neo-Eulerian representations also share the property, which is clear from the general definition in Eq.~(\ref{\chabbr:eq:neoEulerian}), that all rotations around a given axis $\hat{\mathbf{n}}$ lie along a straight line through the origin (since $f(0)=0$).

Using the functions $f(\omega)$ for the various representations, it is easy to show that we have:

\subsection{Composition of rotations in the neo-Eulerian representations}\label{\chabbr:ssec:neoEuleriancomposition}
When rotations are expressed in terms of Euler angles, multiple rotations can be combined into a single rotation by first converting the Euler angles to rotation matrices and then multiplying those matrices together.  Combining rotations in the neo-Eulerian representations is particularly straightforward in the quaternion representation since this representation only requires the direct multiplication of the corresponding unit quaternions.  As an example, consider the rotations $60^{\circ}@[110]$ followed by the rotation $90^{\circ}@[001]$.  Using the standard conversion to quaternions (and remembering to take half of the rotation angle) we have
\[
	q_1 = [\frac{\sqrt{3}}{2}, [\frac{1}{2\sqrt{2}},\frac{1}{2\sqrt{2}},0]]\text{ and }q_2 = [\frac{1}{\sqrt{2}},[0,0,\frac{1}{\sqrt{2}}]]\ .
\]
Since these are passive rotations we multiply them from left to right using the standard quaternion multiplication rule:
\begin{equation*}
\begin{split}
	q=q_1\,q_2 &= \left[q_{1,0}q_{2,0}-\mathbf{q}_1\cdot\mathbf{q}_2, q_{1,0}\mathbf{q}_2+q_{2,0}\mathbf{q}_1+\mathbf{q}_1\times\mathbf{q}_2\right]\ ;\\
	&= \left[ \frac{\sqrt{3}}{2\sqrt{2}}, \left[ \frac{1}{2},0,\frac{\sqrt{3}}{2\sqrt{2}}\right]\right]\ ,
\end{split}
\end{equation*}
which represents a rotation of $104.48^{\circ}$ around the unit axis $[0.632456, 0, 0.774597]$.

In the Rodrigues representation we can make use of the \indexit{Rodrigues composition formula} which reads:
\begin{equation}
	\bm{\rho} = \frac{\bm{\rho}_1+\bm{\rho}_2+\bm{\rho}_1\times\bm{\rho}_2}{1-\bm{\rho}_1\cdot\bm{\rho}_2}\ .\label{\chabbr:eq:RodComp}
\end{equation}
The Rodrigues vectors can be derived from the quaternions above:
\[
	\bm{\rho}_1 = \frac{\mathbf{q}_1}{q_{1,0}}=\left[\frac{1}{\sqrt{6}},\frac{1}{\sqrt{6}},0\right]\text{ and }\bm{\rho}_2=\frac{\mathbf{q}_2}{q_{2,0}}=[0,0,1]
\]
Substitution in the composition formula results in 
\[
	\bm{\rho} = \left[\sqrt{\frac{2}{3}},0,1\right]\ .
\]
This is in agreement with the quaternion product computed above; simply dividing the vector part of $q$ by the scalar part results in the same Rodrigues vector, as is readily verified.  

From a numerical point of view, the quaternion product is the most efficient way to combine two or more rotations; there are fewer multiplications and additions involved than for matrix multiplication, and the Rodrigues composition formula involves a division operation which can be expensive in terms of CPU clock cycles.  The numerical efficiency of quaternion operations explains why they are widely used in the computer gaming industry.


\subsection{Metric properties of neo-Eulerian representations}\label{\chabbr:ssec:neoEulerianmetric}
In section~\ref{\chabbr:sec:eulermetric} we derived the metric tensor for Euler space.\footnote{This section uses rather advanced mathematics and may be skipped on first reading.} In a similar way, the metric tensor for each of the neo-Eulerian representations can be derived. It can be shown \cite{kumar1998a} that the metric tensor for the neo-Eulerian representations has the general form (for rotation angle $\omega$ and a unit rotation axis $\hat{\mathbf{n}}$ with components $n_i$):
\begin{equation}
	g_{ij} = a\left(\delta_{ij}+b\,n_i\,n_j\right)\ ,
\end{equation}
where ($f^{\prime}(\omega)$ represents the derivative of $f(\omega)$ with respect to $\omega$)
\begin{equation}
\begin{split}
	a &= \frac{1-\cos\omega}{2f^2(\omega)}\ ;\\
	b &= \frac{f^2(\omega)}{2f^{\prime 2}(\omega)(1-\cos\omega)}-1\ .
\end{split}
\end{equation}

As an example, we compute the metric tensor for the Rodrigues representation; using $f(\omega)$ and $f'(\omega) = \frac{1}{2}\sec^2(\frac{\omega}{2})$ we find that:
\[
	a=\cos^2\left(\frac{\omega}{2}\right)\text{ and } b=-\sin^2\left(\frac{\omega}{2}\right)\ .
\]
Therefore we have:
\begin{equation}
	g_{ij} = \cos^2\left(\frac{\omega}{2}\right)\left(\delta_{ij}-\sin^2\left(\frac{\omega}{2}\right)\,n_i\,n_j\right)\ ,\label{\chabbr:eq:metricRodrigues}
\end{equation}
and for the Jacobian determinant and the volume element we find:
\[
	J = \cos^4\left(\frac{\omega}{2}\right)\rightarrow \mathrm{d}V = \cos^4\left(\frac{\omega}{2}\right) \mathrm{d}\rho_1\,\mathrm{d}\rho_2\,\mathrm{d}\rho_3\ .
\]
Similarly, for the 3D stereographic representation we find:
\[
	a=4\cos^4\left(\frac{\omega}{4}\right)\text{ and } b=0\ .
\]
Therefore we have:
\begin{equation}
	g_{ij} = 4\cos^4\left(\frac{\omega}{4}\right)\delta_{ij}\ ,\label{\chabbr:eq:metricStereographic}
\end{equation}
and for the Jacobian determinant and the volume element we find:
\[
	J = 8\cos^6\left(\frac{\omega}{4}\right)\rightarrow \mathrm{d}V = 8\cos^6\left(\frac{\omega}{4}\right) \mathrm{d}s_1\,\mathrm{d}s_2\,\mathrm{d}s_3\ .
\]
The expressions for the homochoric representation are not particularly difficult to derive but they are more complicated so we omit them here. The only noteworthy comment is that the Jacobian is equal to $1$, since this is an equal-volume mapping from the unit quaternion sphere $\mathbb{S}^3$ onto a closed ball with the same volume.  Therefore, the volume element for the homochoric representation is given by:
\[
	\mathrm{d}V =  \mathrm{d}h_1\,\mathrm{d}h_2\,\mathrm{d}h_3\ .
\]
It should be noted that in the literature on these representations, the metric tensors may have a scaling factor up front; this factor is used to guarantee that an integration over the whole space for a given representation has a specific value, often $1$, but not always.  The reader should be aware that there are several different potential scaling factors in use.

While this section contains some more advanced math than the rest of this chapter, it is important for the reader to appreciate the fact that these rotation spaces do not generally have simple Cartesian metrics; as a consequence, whenever one performs integrations over orientation distributions expressed in these representations, one must follow the rules of differential geometry to properly carry out the computations.  The paper by Kumar and Dawson \cite{kumar1998a} represents a good starting point for the interested reader.

\subsection{Quaternions and the Euler Angle Representation}\label{\chabbr:sec:quateuler}

In section~\ref{\chabbr:sec:eulerangles} we defined the Bunge Euler angles as the triplet $(\varphi_1,\Phi,\varphi_2)$, and the ranges of the angles are $[0\ldots 2\pi]$ for the angles $\varphi_i$ and $[0\ldots \pi$ for $\Phi$.  In section~\ref{NUMSYS:ssec:EulerFormula} of the Number Systems Foundational chapter, it is shown that Euler's 2D exponential rotation formula can be generalized for quaternions to read:
\begin{equation}
	q = \mathrm{e}^{\hat{\mathbf{n}}\frac{\omega}{2}} = \left[\cos\frac{\omega}{2},(n_x\mathrm{i}+n_y \mathrm{j}+n_z \mathrm{k})\sin\frac{\omega}{2}\right]\ .\label{\chabbr:eq:quatrot}
\end{equation}
For the three Euler rotations, we can thus write down the explicit rotation quaternions in exponential notation as:
\begin{equation}
\begin{split}
	q_1(\varphi_1) &= \mathrm{e}^{\mathrm{k}\frac{\varphi_1}{2}} = \cos\left(\frac{\varphi_1}{2}\right) + \mathrm{k} \sin\left(\frac{\varphi_1}{2}\right)\ ;\\
	q_2(\Phi) &= \mathrm{e}^{\mathrm{i}\frac{\Phi}{2}} = \cos\left(\frac{\Phi}{2}\right) + \mathrm{i} \sin\left(\frac{\Phi}{2}\right)\ ;\\
	q_3(\varphi_2) &= \mathrm{e}^{\mathrm{k}\frac{\varphi_2}{2}} = \cos\left(\frac{\varphi_2}{2}\right) + \mathrm{k} \sin\left(\frac{\varphi_2}{2}\right)\ .
\end{split}
\end{equation}
It should be noted that the periodicity of each of these quaternions $q_i$ requires a rotation by a $4\pi$ angle in order to return to the original quaternion. This is due to the fact that a rotation by $2\pi$ simply changes the sign of the quaternion due to the double cover property (namely that $q$ and $-q$ represent the same rotation).  From the quaternion perspective, the Euler angles ``live'' in a space of dimension $[4\pi,4\pi,4\pi]$. Since, in practice, the texture community employs the standard ranges $[2\pi,\pi,2\pi[$ for the Euler angles, this larger quaternionic repeat unit will not be important, but care should be taken in conversions between quaternions and Euler angles to make sure that the angles end up in the proper sub-region of the larger cell.



\section{The Cubochoric Orientation Representation}\label{\chabbr:sec:cubochoric}
In this section, we introduce an orientation representation that does not belong to the class of neo-Eulerian representations; the new representation takes an orientation, represented by a homochoric vector $\mathbf{h}$, and expresses it as a point $\mathbf{c}$ inside a cube, $\mathbb{C}^3_{\rho}$, with volume $\pi^2$ (and thus edge length $\rho=\pi^{2/3}$).  Note that $\pi^2$ is also the volume of the Northern hemisphere of $\mathbb{S}^3$ as well as the volume of the homochoric representation ball.  The cubochoric representation was introduced in \cite{degraef2014r} with the specific purpose of creating an equal-volume mapping between a cube and a ball, specifically the homochoric ball $\mathbb{B}^3_{\alpha}$ which has radius $\alpha=(3\pi/4)^{1/3}$.  This ball is, itself, an equal-volume Lambert map from the Northern hemisphere $\mathbb{S}^3_+$ of the quaternion unit sphere $\mathbb{S}^3$. The concatenation of the two mappings thus establishes a bi-directional equal-volume map from $\mathbb{S}^3_+$ onto $\mathbb{C}^3_{\rho}$.  The reason for creating an equal-volume mapping is simple: if we create a regular grid of points inside the cube, then this will be mapped onto a regular grid of orientations in $\mathbb{S}^3_+$.

The transformations between the cubochoric and homochoric representations given below are somewhat complicated, and are based on the decomposition of cube and ball into six pyramidal sub-volumes, as shown in Fig.~\ref{\chabbr:fig:exploded}; for a detailed derivation, see \cite{degraef2014r}.

\begin{figure}[b!]
\centering\leavevmode
\includegraphics[width=0.9\textwidth]{\graphicspath exploded.pdf}
\caption{\label{\chabbr:fig:exploded}Exploded views of the cubochoric cube $\mathbb{C}^3_{\rho}$ with the radius set to $\rho=\pi^{2/3}$ and the homochoric ball $\mathbb{B}^3_{\alpha}$ with radius $\alpha=(3\pi/4)^{1/3}$.  Each sector of the sphere is mapped using an equal-volume mapping onto the corresponding pyramidal sector of the cube.}
\end{figure}


\subsection{From cubochoric to homochoric coordinates}
In the relations below, note that $q$, $c$ and $s$ are auxiliary parameters; they are redefined several times throughout the algorithm.

\begin{enumerate}
	\item Rearrange the components of $\mathbf{c}$ according to the pyramid in which it lies:  $1,2\rightarrow$ no change needed;
	$3,4\rightarrow \mathbf{c}=(c_2,c_3,c_1)$; $5,6\rightarrow \mathbf{c}=(c_3,c_1,c_2)$.
	\item Scale $\mathbf{c}$ to $\mathbf{C} = \mathbf{c}(\pi/6)^{1/6}$;
	\item If $\mathbf{C}=\mathbf{0}$ then set $\bm{\lambda}=\mathbf{0}$, else if $\mathbf{C}$ lies along the $z$-axis (first two components are zero) then 
	$\bm{\lambda}=(0,0,C_3\sqrt{6/\pi})$; go to item 5.
	\item In all other cases we have a general grid point; if $\vert C_2\vert \le \vert C_1\vert$ then
	\begin{equation*}
	\begin{split}
		q &= \frac{\pi}{12}\frac{C_2}{C_1}\rightarrow c = \cos(q)\text{ and }s = \sin(q)\ ;\\
		q &= \sqrt{\frac{6}{\pi}}2^{\frac{1}{4}} \frac{C_1}{\sqrt{\sqrt{2}-c}}\rightarrow T_1 = (c\sqrt{2}-1)q\text{ and }T_2 = s\,q\,\sqrt{2}\ , 
	\end{split}
	\end{equation*}
	else ( $\vert C_2\vert > \vert C_1\vert$)
	\begin{equation*}
	\begin{split}
		q &= \frac{\pi}{12}\frac{C_1}{C_2}\rightarrow c = \cos(q)\text{ and }s = \sin(q)\ ;\\
		q &= \sqrt{\frac{6}{\pi}}2^{\frac{1}{4}} \frac{C_2}{\sqrt{\sqrt{2}-c}}\rightarrow T_1 = s\,q\,\sqrt{2}\text{ and }T_2 = (c\sqrt{2}-1)q\ .
	\end{split}
	\end{equation*}
	Then transform to the sphere grid:
	\begin{equation*}
	\begin{split}
		c &= T_1^2+T_2^2\rightarrow s = \frac{\pi c}{24 C_3^2}\text{ and }c = \sqrt{\frac{\pi}{24}}\frac{c}{C_3}\ ;\\
		q &= \sqrt{1-s};\\
		\bm{\lambda} &= (q\,T_1, q\,T_2, \sqrt{\frac{6}{\pi}}C_3-c).
	\end{split}
	\end{equation*}
	\item Finally, rearrange the components of $\bm{\lambda}$ back into the correct order depending on
	the pyramid number: $1,2\rightarrow \mathbf{h}=\bm{\lambda}$; $3,4\rightarrow \mathbf{h}=(\lambda_3,\lambda_1,\lambda_2)$;
	$5,6\rightarrow \mathbf{h}=(\lambda_2,\lambda_3,\lambda_1)$.  
\end{enumerate}

\subsection{From homochoric to cubochoric coordinates}
Given the homochoric vector, $\mathbf{h}$ with $\vert\mathbf{h}\vert\le (3\pi/4)^{1/3}$, one can obtain the cubochoric vector, $\mathbf{c}$, by means of the following steps
(note that $a$, $p$, $q$ and $r$ are auxiliary parameters that are redefined several times):
\begin{enumerate}
	\item If this is the identity rotation, then $\mathbf{c}=\mathbf{0}$ and exit.
	\item Determine which pyramidal section $\mathbf{h}$ is part of, and rearrange the components $h_i$
	accordingly: pyramids $1,2\rightarrow$ no change; $3,4\rightarrow\,\mathbf{h}=(h_2,h_3,h_1)$; 
	$5,6\rightarrow\, \mathbf{h}=(h_3,h_1,h_2)$.
	\item Using the rearranged $\mathbf{h}$, put $q=(2\vert\mathbf{h}\vert/(\vert\mathbf{h}\vert+\vert h_3\vert))^{1/2}$;
	then compute 
	\[
		\mathbf{h}' = \left( q h_1, q h_2, \text{sign}(h_3)\vert\mathbf{h}\vert/\sqrt{6/\pi} \right)
	\]
	\item Set $p = h_1^{\prime 2}+h_2^{\prime 2}$; if $h'_1 \ne 0\rightarrow s_x=\text{sign}(h'_1)$, else $s_x=1$;
	if $h'_2\ne 0\rightarrow s_y=\text{sign}(h'_2)$, else $s_y=1$;
	\item If $\vert h'_2\vert \le \vert h'_1\vert$ then compute
	\begin{align*}
		q &= p + h_1^{\prime 2};\\
		r &= \sqrt{q};\\
		q &= \frac{\pi^{5/6}4^{1/3}}{2\sqrt{2}\,(3\pi)^{1/3}6^{1/6}}\sqrt{\frac{q\, p}{(q-\vert h'_1\vert r)}};\\
		a &= \arccos( (h^{\prime 2}_2+\vert h'_1\vert r)/\sqrt{2}/p);\\
		T_1 &= q\, s_x;\\
		T_2 &= 12 q\, s_y\, a/\pi.
	\end{align*}
	else ($\vert h'_1\vert \le \vert h'_2\vert$)
	\begin{align*}
		q &= p + h_2^{\prime 2};\\
		r &= \sqrt{q};\\
		q &= \frac{\pi^{5/6}4^{1/3}}{2\sqrt{2}\,(3\pi)^{1/3}6^{1/6}}\sqrt{\frac{q\, p}{(q-\vert h'_2\vert r)}};\\
		a &= \arccos( (h^{\prime 2}_1+\vert h'_2\vert r)/\sqrt{2}/p);\\
		T_1 &= 12 q\, s_x\, a/\pi;\\
		T_2 &= q\, s_y.
	\end{align*}
	Then set $\mathbf{h}''= (6/\pi)^{1/6}(T_1, T_2, h'_3)$.
	\item Finally, revert the components back to the original order (undoing the pyramid swap): 
	$1,2\rightarrow \mathbf{c}=\mathbf{h}''$; $3,4\rightarrow \mathbf{c}=(h''_3,h''_1,h''_2)$; and
	$5,6\rightarrow \mathbf{c}=(h''_2,h''_3,h''_1)$.
\end{enumerate}

\section{Summary of important orientation/rotation representations}\label{\chabbr:sec:rotationmap}

Fig.~\ref{\chabbr:fig:RotationMap} shows some of the relations between the various representations introduced in the preceding sections.  The simplest representation, the axis-angle representation, simply states the rotation angle, $\omega$, and the unit rotation axis, $\hat{\mathbf{n}}$ with respect to a suitably chosen cartesian reference frame. From $\omega@\hat{\mathbf{n}}$ we can construct the $3\times 3$ special orthogonal rotation matrix $R_{ij}$ by means of the relation:
\[
	R_{ij} = \delta_{ij}\cos\omega+(1-\cos\omega)n_in_j-\sin\omega\,\epsilon_{ijk} n_k\ ,
\]
where $\epsilon_{ijk}$ is the permutation symbol and $n_i$ are the components of $\hat{\mathbf{n}}$. From the axis-angle representation one can derive all the neo-Eulerian representations of the form $\hat{\mathbf{n}}\,f(\omega)$; they are shown in the light-blue oval. The quaternions are represented by a circle that is partially outside the blue oval; this is due to the fact that only the vector part, $\mathbf{q}$, of the quaternion has a neo-Eulerian form. The cubochoric representation, $\mathbf{c}$, introduced in section~\ref{\chabbr:ssec:cubochoric}, does not have a neo-Eulerian form and needs the homochoric representation as a starting point. The red arrows indicate frequently used transformations between the representations.  Of these transformations, quaternion$\leftrightarrow$stereographic is noteworthy because it is an equal-angle mapping; both quaternion$\leftrightarrow$homochoric and homochoric$\leftrightarrow$cubochoric are equal-volume mappings which makes them particularly well suited for orientation sampling, as described in the next section.

\section{The Clifford Torus}\label{\chabbr:sec:CliffordTorus}
Any unit quaternion $q$ on the hyper-sphere $\mathbb{S}^3$ can be expressed in terms of two angles, $\theta$ and $\varphi$, each angle in the range $[-\pi,\pi]$, by means of the following expression:
\begin{equation}
	q = \frac{1}{\sqrt{2}}[\cos\theta,\sin\theta,\cos\varphi,\sin\varphi]\ ;\label{\chabbr:eq:CliffordTorus}
\end{equation}
the prefactor guarantees that this is a quaternion with unit norm. In terms of the quaternion components, it is easy to see that $q_0^2+q_1^2=\frac{1}{2}$ and $q_2^2+q_3^2=\frac{1}{2}$; since the quaternion components ``lie'' along four orthogonal directions, these two expressions represent two orthogonal circles. The combination of two orthogonal circles, each parameterized independently by an angle in the interval $[-\pi,\pi]$, generates a \indexit{torus} known as the \indexit{Clifford torus}; in mathematical terms, this is a 2D sub-manifold of $\mathbb{S}^3$.  It is easy to see that there are two other tori, namely the ones generated by pairs of circles in the $q_0$-$q_2$ and $q_1$-$q_3$ planes, as well as the $q_0$-$q_3$ and $q_1$-$q_2$ planes. There are thus three orthogonal Clifford tori, each a 2D sub-manifold of $\mathbb{S}^3$.  Since 3D rotations/orientations have three degrees of freedom, and each torus has only two parameters, this means that an individual 2D Clifford torus can not be used to reconstruct the three-components of a 3D rotation, but the combination of the three tori does contain all three degrees of freedom.  In fact, each unit quaternion vector component is represented in two of the three tori.

There is a close connection between the Clifford torus representation and the Rodrigues representation. The Rodrigues vector corresponding to equation~(\ref{\chabbr:eq:CliffordTorus}) is given by:
\begin{equation}
	\bm{\rho} = \left[ \tan\theta, \frac{\cos\varphi}{\cos\theta},\frac{\sin\varphi}{\cos\theta}\right]=\left[\rho_x,\rho_y,\rho_z\right]\ .
\end{equation}
We can readily express the angles $(\theta,\varphi)$ in terms of the components of $\bm{\rho}$ as:
\begin{equation}
	(\theta,\varphi)_R = \left(\text{arctan}(\rho_x), \text{arctan}\left(\frac{\rho_z}{\rho_y}\right)\right)\ .
\end{equation}
Since each of the angles has a range $[-\pi,\pi]$, and the two corresponding circles are orthogonal, we can represent the rotation $\bm{\rho}$ by a point in a square with side lengths $2\pi$, with $\theta$ along the horizontal axis and $\varphi$ along the vertical axis.  It can be shown that this representation is an isometric projection of the Clifford torus onto a 2D periodic square, periodic since both axes represent an angle.  

We will call the isometric projection of the Clifford torus onto a 2D square a \indexit{square torus map}.  Since there are three different orthogonal Clifford tori, there are thus three independent square torus maps, given by the angle pairs:
\begin{equation}
	(\theta,\varphi)_G = \left(\text{arctan}(\rho_y), \text{arctan}\left(\frac{\rho_x}{\rho_z}\right)\right)\text{ and }(\theta,\varphi)_B = \left(\text{arctan}(\rho_z), \text{arctan}\left(\frac{\rho_y}{\rho_x}\right)\right)\ .
\end{equation}
The subscripts $R$, $G$, and $B$ on the angle pairs are intentionally selected to indicate that each square torus map can be placed in a channel of an RGB (red-green-blue) color image. We have thus constructed an isometric projection from the unit quaternion sphere $\mathbb{S}^3$ to an RGB color image.

As an example, consider the rotation $\pi/3@[111]$, which is represented by the quaternion:
\[
	q=\left[\frac{\sqrt{3}}{2},\frac{1}{2\sqrt{3}},\frac{1}{2\sqrt{3}},\frac{1}{2\sqrt{3}}\right]\ ;
\]
This corresponds to the following Rodrigues vector and square torus map parameters:
\[
	\bm{\rho}=\left[\frac{1}{3},\frac{1}{3},\frac{1}{3}\right]\rightarrow 
	(\theta,\varphi)_{R,G,B} = \left(\text{arctan}\left(\frac{1}{3}\right),\text{arctan}\left(1\right)\right)= (0.321751 , 0.785398)\ ,
\]
where the angles are expressed in radians. When computing the arctan functions, care must be taken to ensure that the result lies in the correct quadrant; numerically, this means that one must use the two-argument form of the arctan function, which is often implemented as \textsf{atan2(x,y)} which stands for arctan$(y/x)$.  The order of the parameters $x$ and $y$ may vary between programming languages.  

It should also be noted that the square torus map coordinates of quaternions $q$ and $-q$ are different.  In terms of the quaternion components, we can express the angles $(\theta,\varphi)$ as:
\[
	(\theta,\varphi)_R = \left(\text{arctan}\frac{q_1}{q_0},\text{arctan}\frac{q_3}{q_2}\right) = \left(\text{atan2}(q_0,q_1),\text{atan2}(q_2,q_3)\right)\ ;
\]
for the rotation $\pi/3@[111]$ from above, a simple computation shows that for quaternion $-q$ we have:
\[
	-q=\left[-\frac{\sqrt{3}}{2},-\frac{1}{2\sqrt{3}},-\frac{1}{2\sqrt{3}},-\frac{1}{2\sqrt{3}}\right]\ 
\]
which leads to the coordinates $(\theta,\varphi)_R=(-2.81984,-2.35619)$, i.e., if the square torus coordinates for $q$ are $(\theta,\varphi)$, then $-q$ projects onto the point $(\theta-\pi,\varphi-\pi)$.

A square torus map can be generated by first determining the coordinates $(\theta_i,\varphi_i)$ for all the orientations in the data set, and then drawing a narrow Gaussian dot at that location in the map; the width of the Gaussian dot can be adjusted as needed.
